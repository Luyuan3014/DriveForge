# 详细更新记录

此目录保存重要项目更新的完整说明。文件名使用 `YYYY-MM-DD-short-name.md`，内容保持事实化，并链接到相关代码、测试或验证产物。

普通小改动只需要更新根目录 `CHANGELOG.md`；满足 [`update-process.md`](../update-process.md) 中条件的变更，应复制下面模板创建新文件。

## 模板

```markdown
# YYYY-MM-DD：更新名称

## 背景

为什么需要这次更新，要解决什么问题。

## 变更范围

- 新增：
- 修改：
- 移除：

## 用户影响

说明 CLI、配置、输出、状态或使用流程的变化。

## 兼容性

说明是否向后兼容、是否需要迁移以及迁移方法。

## 验证

- 自动化测试：
- 构建：
- 真实硬件：

## 已知限制

仍未解决或不在本次范围内的事项。

## 相关文档

- Changelog：
- PR/Commit：
```

测试环境未包含真实硬件时，必须明确写“未进行真实硬件验证”，不能使用 `VERIFIED` 描述模拟结果。
